# 옥토 테트리스

모바일과 PC에서 모두 플레이할 수 있는 단일 HTML 테트리스 게임입니다.

## 실행 방법

브라우저에서 `index.html` 파일을 열면 바로 실행됩니다.

## 조작법

### PC

- `←` / `→`: 좌우 이동
- `↑`: 회전
- `↓`: 빠르게 내리기
- `Space`: 즉시 낙하
- `P`: 일시정지

### 모바일

화면 하단의 터치 버튼을 사용합니다.

- `←` / `→`: 좌우 이동
- `⟳`: 회전
- `↓`: 빠르게 내리기
- `DROP`: 즉시 낙하

## 기능

- 반응형 UI
- 모바일 터치 조작 지원
- PC 키보드 조작 지원
- 점수, 라인, 레벨 표시
- 다음 블록 표시
- 고스트 블록 표시
- 일시정지 / 재시작
- 선택형 효과음

## 파일 구성

- `index.html`: 게임 전체 코드가 포함된 단일 HTML 파일

## 제작 메모

기록하는신문사 대표님의 요청에 따라 모바일 우선, PC 호환 방식으로 제작했습니다.
